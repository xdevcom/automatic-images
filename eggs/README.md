# Pterodactyl Eggs

Egg files for Automation Images.

## Available Eggs

| File | Description |
|------|-------------|
| `egg-node-xdevcom.json` | Node.js Egg using Automation Images |
| `egg-python-xdevcom.json` | Python Egg using Automation Images |

## Import

1. Open your Pterodactyl Admin Panel
2. Go to **Nests**
3. Import the desired Egg
4. Select one of the included Docker Images
